# MarKey

**MarKey** — аналог Punto Switcher для macOS. Исправляет текст, набранный в неправильной раскладке, прямо во время набора: `ghbdtn` → `привет`, `руддщ` → `hello`.

Название: **Mar** от marmos + **Key** от клавиатуры, в одном стиле с MarMic. Основано на [rstqDev/rekey](https://github.com/rstqDev/rekey) (MIT).

## Как пользоваться

1. **Просто печатайте.** Слово в неправильной раскладке исправится в момент, когда вы нажмёте пробел, Enter или Tab. Клавиатура сама переключится на нужную раскладку, и следующее слово пойдёт правильно.
2. **Исправилось зря — нажмите правый ⌘.** Слово вернётся как было, и MarKey запомнит, что его трогать не надо. Ещё одно нажатие вернёт исправление.
3. **Не исправилось — нажмите правый ⌘.** Переведётся слово у курсора и вся фраза перед ним, набранная в неправильной раскладке. MarKey сам найдёт, где она началась. Переписывать ничего не нужно.
4. **Выделили текст — нажмите правый ⌘.** Переведётся выделение, например всё поле после ⌘A. Ваш буфер обмена восстанавливается, а менеджеры буфера (Raycast, Paste, Maccy) эту операцию не записывают.

Клавишу можно сменить в настройках: правый ⌥/⇧/⌃, любой ⌥/⇧/⌃, одно или двойное нажатие. Модификатор, нажатый в сочетании (⌘C, ⌘Tab), хоткей не вызывает.

## Исключения

В настройках, на вкладке «Исключения», можно выбрать любое установленное приложение из списка с иконками и поиском. Ещё быстрее — пункт «Не исправлять в «…»» в меню MarKey в строке меню: он добавляет текущее приложение одним кликом. По умолчанию исключены терминалы и менеджеры паролей. Поля паролей (Secure Input) защищены всегда.

## Что изменилось по сравнению с Rekey

- **Работает в любом текстовом поле.** Codex переделал рантайм на macOS так, что исправление выполнялось только через Accessibility и только в полях, которые отдают свой текст. Любой backspace или несовпадение отменяли коррекцию, поэтому в Electron-приложениях, браузерах и многих чатах ничего не происходило. Теперь коррекция печатается как обычные нажатия клавиш, как у Punto.
- **Пробел и Enter придерживаются до исправления.** Перехват клавиатуры устанавливается как активный фильтр, поэтому клавиша, закончившая слово, отправляется только после исправления. Нет гонок, и Enter в чате не отправляет сообщение с ошибкой. Клавиши, нажатые за эти миллисекунды, ставятся в очередь и повторяются по порядку.
- **Словари.** Полные частотные списки OpenSubtitles для английского, русского и украинского: около 400 тыс. словоформ вместо 50 тыс., ё приравнена к е. Снята «защита» с мусора вроде `lf`, `ye`, `ds`, из-за которого «да», «ну», «вы», «тут», «ещё» не исправлялись никогда.
- **Пунктуация.** `ghbdtn,` → `привет,`, `руддщю` → `hello.`, `кто-то`, `don't`.
- **Контекст фразы.** Предыдущее слово решает спорные случаи. Короткие слова перед исправленным исправляются вместе с ним: `z gjqle` → `я пойду`.
- **Точные раскладки.** Таблицы клавиш берутся из установленных в системе раскладок (UCKeyTranslate), поэтому «Русская» и «Русская – ПК» обрабатываются правильно.
- **Новый интерфейс** в стиле «Системных настроек» macOS, на русском.

### Точность (`cargo run --release -p eval`)

Режим «Обычно», английский ↔ русский:

| Метрика | Было (Rekey) | Стало |
|---|---|---|
| Частые слова (топ-3000), исправлено | 98.7% / 98.9% | 99.5% / 99.7% |
| С учётом частоты употребления, включая короткие | — | 87.6% (en→ru), 92.6% (ru→en) |
| Слова с 50 000-го по 300 000-е место по частоте | 28.8% / 3.6% | 85.9% / 92.8% |
| Слова с запятой или точкой | — | 99.6% / 100% |
| Правильные слова, испорченные зря | 0.00% | 0.00–0.01% |
| Слова с опечаткой, испорченные зря | — | 0.35% (ru), 0.07% (en) |

Цифры получены на корпусе, а не при наборе вживую.

## Сборка

Нужны Rust 1.77+ и Xcode Command Line Tools.

```sh
git clone https://github.com/Marmos1337/MarKey.git
cd MarKey
./tools/fetch_corpora.sh                                              # частотные списки (~60 МБ)
cargo run --release -p modelgen -- tools/.cache crates/rekey-core/data/models
cargo install tauri-cli --version "^2"                                # один раз
cargo tauri build                                                     # или: cargo tauri dev
```

Готовое приложение появится в `target/release/bundle/macos/MarKey.app`. Перенесите его в «Программы», запустите и разрешите доступ: Системные настройки → Конфиденциальность и безопасность → Универсальный доступ → MarKey. Перезапуск не нужен.

macOS привязывает разрешение Универсального доступа к подписи приложения. У ad-hoc-сборки подпись меняется при каждой пересборке: в настройках MarKey остаётся включённым, но доступа у него уже нет. Тогда удалите его из списка кнопкой «−» и добавьте снова, либо выполните `tccutil reset Accessibility com.marmos.markey`. Подпись настоящим сертификатом (`APPLE_SIGNING_IDENTITY`) решает проблему насовсем.

Настройки лежат в `~/Library/Application Support/com.marmos.markey/`. Настройки от сборки Rekey переносятся автоматически при первом запуске. Там же находится журнал `markey.log`: в него пишутся решения и длины слов, сами слова никогда.

## Устройство

```
клавиша ─→ хук (CGEventTap) ─→ движок ─→ детектор ─→ инжектор (backspace + нажатия)
```

- `crates/rekey-core`: независимое от платформы ядро — таблицы раскладок, языковые модели, детектор, движок с историей фразы. Тестируется без клавиатуры и ОС.
- `crates/rekey-hook`: платформенный слой. На macOS — CGEventTap, синтетические события, раскладки из системы, буфер обмена, иконки приложений.
- `app/src-tauri`: приложение в строке меню (Tauri 2), сервис с очередью инжектора.
- `app/ui`: окно настроек.

Внутренние имена crate (`rekey-*`) оставлены, чтобы не ломать историю. Исходная документация Rekey лежит в [docs/REKEY-UPSTREAM.md](docs/REKEY-UPSTREAM.md), архив прошлой разработки — в `archive/`.
