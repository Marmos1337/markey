# MarKey

**MarKey** — персональный форк Rekey от **marmos**, который исправляет текст, набранный в неверной раскладке: `ghbdtn` → `привет`.

Название: **Mar** от marmos + **Key** от клавиатуры, в одном стиле с MarMic.

## Состояние

09.10.2026: исходники, локальные доработки и история сохранены в приватном репозитории [Marmos1337/MarKey](https://github.com/Marmos1337/MarKey). Это архив текущей разработки, не новый готовый релиз.

- Разработка runtime остаётся приостановленной. По архиву 02.10.2026 последний runtime-результат установленной V5 — **FAIL**.
- V6-r2 не одобрена для установки: остаются блокировка операции reconciler/AX transaction и повторная проверка владения после последнего AX IPC перед выбором раскладки.
- В рамках переноса приложение не собиралось, не устанавливалось и не проходило новую runtime-приёмку.
- Имена Rust crates, bundle ID `app.rekey.desktop` и имя установленного приложения сохранены для совместимости. MarKey сейчас — название форка и репозитория.

## Содержимое

- `app/`, `crates/`, `tools/`, `web/`, `automation/` — полный сохранённый исходный проект с локальными доработками.
- `archive/rekey-2026-10-02/` — Git bundle со всеми архивными refs, patch, manifest и исторические отчёты. Их PASS/FAIL относятся к прошлым проверкам.
- [Инвентаризация](docs/INVENTORY.md) — найденные файлы и исключения.
- [Исходная документация Rekey](docs/REKEY-UPSTREAM.md) — архитектура и инструкции upstream; приведённые там показатели не перепроверялись при переносе.

## Разработка

```sh
git clone https://github.com/Marmos1337/MarKey.git
cd MarKey
```

Проект использует Rust workspace и Tauri. Генерация языковых моделей описана в исходной документации; модели и корпуса исключены из Git как производные данные. Перед установкой необходимо отдельно завершить перечисленные runtime-доработки и проверки.
