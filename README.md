# MarKey

MarKey исправляет текст, набранный в неправильной раскладке: `ghbdtn` → `привет`, `руддщ` → `hello`.

Приложение работает в фоне. В настройках можно выбрать языки, назначить горячую клавишу для ручного переключения и указать приложения, в которых исправления не нужны. Можно также перевести выделенный текст в другую раскладку.

## Установка на Mac

1. Скачайте и откройте DMG.
2. Перетащите MarKey в «Программы» и запустите.
3. Разрешите MarKey доступ в **Системные настройки → Конфиденциальность и безопасность → Универсальный доступ**.

После запуска значок появится в строке меню. Через него можно открыть настройки или приостановить исправления.

Версия 0.2.0 пока без нотариализации Apple. Если macOS блокирует запуск, подтвердите открытие именно MarKey в разделе «Конфиденциальность и безопасность». При обновлении удалите старую запись MarKey из «Универсального доступа» кнопкой «−» и добавьте приложение заново: без этого переключатель остаётся включённым, но доступа у новой версии нет.

## Установка на Windows

1. Скачайте файл `MarKey_0.2.0_x64-setup.exe`.
2. Запустите установщик и следуйте его подсказкам.
3. Откройте MarKey через меню «Пуск». Настройки доступны через значок в области уведомлений.

Установщик пока без цифровой подписи издателя. Для окна настроек нужен Microsoft Edge WebView2; установщик предложит его установить, если компонента нет в системе.

## Использование

Выберите нужные языки и включите автоматическое исправление. Если слово исправилось не так, используйте горячую клавишу для отмены: по умолчанию это правый ⌘ на Mac и правый Ctrl на Windows. Программы, где исправления мешают, добавьте в исключения.
