# MarKey 0.3.2

## Что нового

- Поле проверки в настройках исправляет слова и позволяет отменить последнее исправление. Раньше собственное окно MarKey исключалось из глобального обработчика клавиатуры, поэтому проверка ничего не делала.
- Игры и исключённые приложения не попадают в очередь исправлений. Наблюдение за мышью больше не выполняет работу в глобальном перехватчике мыши.
- При переключении окна устаревшее исправление отменяется; сочетания клавиш сохраняют состояние уже зажатых модификаторов.

## What's new

- The practice field in settings now corrects words and supports undo. MarKey's own window was excluded from its global keyboard handler, which left the previous practice field inactive.
- Games and excluded applications stay outside the correction queue. Mouse observation no longer runs in a global mouse hook.
- Corrections bound to a previous window are discarded, and injected shortcuts preserve modifiers already held by the user.

## Verification and limits

The source changes were checked with JavaScript and Rust tests, a native WebView practice-field test, and an owned Windows editor with canned text. Both the previous release and the candidate passed the separate editor test; a general failure in every application was not reproduced. These checks do not establish Counter-Strike performance or resolve the reported physical-key release issue.

Windows packaging is prepared separately from publication. macOS packages and installation acceptance require their own checks; do not reuse an older package under this version.
